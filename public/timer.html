    Кто выбыл?

    Нажмите фамилию. Игрок получит текущее место, счётчик обновится, финальный стол заполнится сам.

    Esc — закрыть  ·  клавиша + возвращает последнего выбывшего

    Настройки турнира

    Заполните перед турниром. Всё сохраняется в этом браузере на этом ноутбуке.

    Одна строка — один игрок. Из этого списка строится рассадка, считаются оставшиеся игроки и сам заполняется финальный стол. «Раскидать игроков заново» перемешивает порядок и обнуляет выбывания.
    Одна строка — один турнир: 4 октября; сб; Rebuy Турнир; 20:00 · вход 3000 ₽. Показывается по клавише A.
    Три строки: первая — победитель. Формат: Максим Королёв; +300 очков. Показывается по клавише W.
    Одна строка — один участник: Максим Королёв; 1820. Вместо очков можно писать что угодно — стек, призовые. Показывается по клавише L.
    Одна строка — один уровень: малый большой анте. Если анте нет, пишите только два числа: 100 200.
    Своя длина уровня — четвёртым числом: 100 200 200 30 (30 минут). Без анте, но со своей длиной: 100 200 0 30.
    Перерыв — отдельной строкой: перерыв 10. Аддон-тайм — строкой аддон 15: это тот же перерыв, но на экране объявляется покупка аддона.
